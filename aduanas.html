¿Esta declaración es probable fraude?

Ingresa los datos de una declaración de importación. El modelo entrenado con el dataset Bangladesh Customs Fraud Detection (Kaggle) estimará si presenta indicios de fraude.

Mercancía
Código numérico, hasta 8 dígitos
Total Tax Incidence, mayor o igual a 0
Ruta
Por ejemplo, Chittagong Sea Port
Código de 2 letras, por ejemplo CN
Si difiere del origen, hay triangulación
Peso y valor
Mayor que 0
Vacío si la carga no pasó por escáner
En takas de Bangladesh, mayor que 0
